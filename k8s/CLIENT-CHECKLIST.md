# MONSTER HOUSE 오픈 전 준비 목록

사이트는 다 만들어졌고, 아래 항목만 준비되면 바로 오픈할 수 있습니다.
**전부 한 번만 하면 되는 일**이고, 계정 만드는 것 외에는 개발자가 처리합니다.

---

## 1. 도메인 (필수)

주소를 정해주세요. 예: `monsterhouse.co.kr`, `monsterhouse.kr`

- 가비아·후이즈 등에서 구매 (`.com` 연 1.5만원 안팎, `.co.kr` 연 2만원 안팎)
- **구매만 하시면 됩니다.** 연결 설정은 개발자가 합니다.
- 아직 못 정하셨으면 임시 주소로 먼저 열고 나중에 바꿔도 됩니다.

## 2. 서버 (필수)

두 가지 중 하나입니다.

| | 비용 | 비고 |
|---|---|---|
| Oracle Cloud 무료 | **0원** | 평생 무료. 가입만 하면 됩니다 |
| AWS | 월 4~5만원 | 국내 접속이 조금 더 빠릅니다 |

Oracle 무료로도 충분합니다. **계정만 만들어 주시면** 나머지는 개발자가 합니다.
(카드 등록을 요구하지만 무료 범위에서는 청구되지 않습니다)

## 3. 예약 알림 받을 곳 (권장)

예약이 들어오면 알려드리는 통로입니다. 안 하시면 **관리자 페이지를 직접 열어봐야
새 예약을 알 수 있습니다.**

- **메일** — 알림 보낼 계정 하나 (Gmail 이면 "앱 비밀번호" 발급 필요)
- **LINE** — 일본 고객 문의도 받으시려면. LINE Developers 채널 생성 필요

둘 다 나중에 추가해도 되지만, **메일 하나는 오픈 전에 켜두시길 권합니다.**

## 4. 콘텐츠 (오픈 전)

관리자 페이지에서 직접 넣으실 수 있습니다. 개발자가 사용법을 알려드립니다.

- [ ] **촬영 상품** — 이름·가격·소요시간·포함사항
- [ ] **영업시간** — 요일별 시간, 정기 휴무일
- [ ] **갤러리 사진** — ⚠ **모델 동의를 받은 것만** 올려주세요
- [ ] **대회 일정** — 한국·일본
- [ ] 소개 글 (선택)

> **초상권 안내**
> 갤러리는 동의 체크를 하기 전까지 손님에게 보이지 않습니다.
> 동의를 언제 어떻게 받았는지(예: "2026-08-01 카톡 동의") 함께 기록해 주세요.
> 나중에 문제가 생겼을 때 근거가 됩니다.

## 5. 일본어 감수 (오픈 전 권장)

현재 일본어는 **기계번역 초안**입니다. 문법은 맞지만 어색한 표현이 있을 수 있습니다.
일본어가 가능한 분께 한 번 봐달라고 하시면 좋습니다.

감수 없이 열어도 동작에는 문제없지만, 일본 고객이 첫인상에서 신뢰를 잃을 수 있습니다.
