# AWS 가입 + 개발자 계정 발급 — 사장님용 가이드

MONSTER HOUSE 서버를 AWS에 올리기 위해, 사장님은 딱 두 가지만 하시면 됩니다.

1. **AWS 계정 만들기** (회원가입)
2. **개발자용 계정(IAM 사용자) 만들어서 개발자에게 로그인 정보 전달**

그 다음 서버 만들기·설치·배포·도메인 연결은 **개발자가 그 계정으로 직접** 합니다.
(약 20~30분. 카드 등록만 사장님 명의로 하면 됩니다.)

> 💡 왜 "개발자 계정"을 따로 주나요?
> 사장님의 **주 계정(루트) 비밀번호를 넘기면 위험**합니다(결제·계정삭제까지 다 열림).
> 그래서 **권한이 제한된 개발자용 계정(IAM)** 을 하나 만들어 그것만 넘깁니다.
> 문제가 생기면 그 계정만 잠그면 되고, 사장님 본 계정은 안전합니다.

---

## PART A. AWS 계정 만들기 (회원가입)

### 준비물
- 본인 명의 휴대폰 (본인인증)
- 신용/체크카드 (계정 확인용 — 서버 만들기 전엔 청구 안 됨)
- 이메일 주소

### 절차
1. https://aws.amazon.com/ko 접속 → **"AWS 계정 생성"**
2. 이메일·비밀번호·계정 이름 입력
3. 연락처 정보(개인) 입력
4. **결제 카드 등록**
5. 휴대폰 문자/전화 **본인인증**
6. 지원 플랜 = **"기본 지원 - 무료"**

> ⚠️ 계정 생성은 5~10분, 드물게 카드 확인에 몇 시간. 다 되면 이메일이 옵니다.
> 이때 만든 이메일·비밀번호가 **루트(주인) 계정**입니다. **절대 개발자에게 주지 마세요.**

---

## PART B. 개발자용 계정(IAM 사용자) 만들기

이제 개발자가 쓸 **제한된 계정**을 하나 만듭니다.

1. AWS 로그인(루트 계정) → 상단 검색창에 **`IAM`** 입력 → 클릭
2. 왼쪽 메뉴 **"사용자(Users)"** → **"사용자 생성(Create user)"**
3. **사용자 이름**: `jaeyoon-dev` (아무거나 알아보기 쉽게)
4. **"AWS Management Console에 대한 사용자 액세스 권한 제공"** 체크
   - "IAM 사용자를 생성하고 싶음" 선택
   - **콘솔 비밀번호**: "자동 생성됨" 선택
   - **"사용자는 다음 로그인 시 새 암호를 생성해야 합니다"** 체크 (개발자가 첫 로그인 때 새 비번 설정)
5. **다음** → 권한 설정
   - **"직접 정책 연결(Attach policies directly)"** 선택
   - 검색창에 **`AdministratorAccess`** → 체크
   > 개발자가 서버·배포를 전부 다뤄야 하므로 관리 권한을 줍니다.
   > (혼자 신뢰하는 개발자이므로 OK. 나중에 범위를 좁히고 싶으면 개발자가 도와드립니다.)
6. **다음 → 사용자 생성**
7. 생성 완료 화면에서 아래 **3가지가 나옵니다. 꼭 메모/캡처하세요** (이게 PART C에서 넘길 값):
   - **콘솔 로그인 URL** (예: `https://123456789012.signin.aws.amazon.com/console`)
   - **사용자 이름** (`jaeyoon-dev`)
   - **콘솔 비밀번호** (임시)
   > "CSV 다운로드" 버튼이 있으면 눌러 저장해두면 편합니다.

---

## PART C. ✅ 개발자에게 넘겨줄 정보 (이게 핵심)

아래 **3가지**만 개발자에게 전달하면 끝입니다.

| # | 항목 | 예시 | 어디서 |
|---|---|---|---|
| 1 | **콘솔 로그인 URL** | `https://123456789012.signin.aws.amazon.com/console` | PART B-7 |
| 2 | **사용자 이름** | `jaeyoon-dev` | PART B-3 |
| 3 | **임시 비밀번호** | (자동 생성된 값) | PART B-7 |

이 3가지면 개발자가 로그인해서 **서버 생성 → 설치 → 도메인 연결**까지 직접 합니다.

### 🔒 안전하게 전달하는 법
- 비밀번호를 카톡 일반 대화에 그냥 올리기 ❌
- **추천**: URL·사용자이름은 카톡/문자로, **비밀번호는 전화로 불러주거나 카톡 "비밀채팅"**으로.
- 개발자가 첫 로그인 때 비밀번호를 새로 바꾸므로, 임시 비번이 새어도 위험이 줄어듭니다.

## PART D. 사장님 계정 보안 (5분, 강력 권장)

개발자에게 넘기는 것과 별개로, **사장님 루트 계정**은 이렇게 지키세요.

1. **루트 계정에 MFA(2단계 인증) 켜기**
   - IAM 첫 화면 또는 우측 상단 계정 메뉴 → **"보안 자격 증명"** → **MFA 활성화**
   - 휴대폰 앱(Google Authenticator 등)으로 6자리 코드 인증 추가
   - ⚠ 이걸 켜면 비밀번호가 새어도 휴대폰 없이는 로그인 불가 → 가장 확실한 보호
2. **결제 알림 걸어두기** (예상보다 많이 나오면 메일)
   - 상단 검색 **`Billing`** → **결제 기본 설정** → 결제 알림 받기 체크
   - (구체적 금액 알림은 개발자가 도와드릴 수 있습니다)
