# 카페24 서버 만들기 — 사장님용 가이드

MONSTER HOUSE 웹사이트를 올릴 **서버**를 카페24에서 만드는 과정입니다.
서버를 만들고 **접속 정보 3가지를 개발자에게 전달**하면 나머지 설치는 개발자가 합니다. (약 15~20분)

> 💡 **도메인(monsterhouse.co.kr)은 가비아에 그대로 둡니다.** 서버만 카페24에 만들고,
> 나중에 가비아에서 "주소 연결"만 해주면 됩니다(STEP 8). 헷갈릴 것 없습니다.

> ⚠️ 카페24 화면은 수시로 바뀝니다. 버튼 이름이 조금 다르면
> **"가상서버호스팅", "클라우드 서버"** 같은 단어를 기준으로 찾으시면 됩니다.

---

## 준비물

- **본인 명의 휴대폰** (본인인증용)
- **결제 수단** (신용/체크카드 또는 계좌이체)

---

## STEP 1. 카페24 회원가입 / 로그인

1. https://www.cafe24.com 접속
2. 로그인 (없으면 회원가입 → 본인인증)

---

## STEP 2. "가상서버호스팅(VPS)" 신청

⚠️ **여기가 제일 중요합니다. 반드시 "서버"를 사야 합니다.**

- 메뉴에서 **"호스팅 → 가상서버호스팅"** 또는 **"클라우드 → 클라우드 서버"** 를 찾습니다.
- **하지 말 것**: **"웹호스팅"** 은 고르지 마세요. 우리 사이트를 못 돌립니다.

| 사야 하는 것 ✅ | 사면 안 되는 것 ❌ |
|---|---|
| **가상서버호스팅 (VPS)** 또는 **클라우드 서버** | 웹호스팅 |
| | 단독서버(전용서버) — 과함·비쌈 |
| | 도메인 (이미 가비아에 있음) |

---

## STEP 3. 서버 사양 고르기

아래대로만 선택하세요.

| 항목 | 선택 |
|---|---|
| **운영체제(OS)** | **Ubuntu 22.04** (없으면 Ubuntu 20.04 등 Ubuntu 최신) |
| **메모리(RAM)** | **4GB** 플랜 (최소 3GB — 2GB 는 안 됩니다) |
| **CPU** | 2 vCPU 이상 (4GB 플랜에 보통 포함) |
| **디스크(SSD)** | **50GB 이상** (플랜에 포함된 용량이면 OK) |
| 요금제 | **월 정액** |

> ⚠️ **메모리는 꼭 4GB 로.** 이 사이트는 백엔드와 데이터베이스를 한 서버에서 같이 돌려서,
> 2GB 로 하면 서버가 자꾸 뻗습니다. 3GB 도 가능하지만 4GB 가 안정적입니다.
> (카페24 VPS 4GB 는 대략 **월 3~4만원대** 입니다.)

> OS 를 CentOS 등으로 기본 선택돼 있으면 **Ubuntu 로 바꿔** 주세요.

---

## STEP 4. 결제

- 서버 이름은 아무거나 (예: `monsterhouse`)
- 결제하면 서버가 만들어집니다. (즉시~몇 분, 카페24는 검토 후 개통되는 경우도 있어 조금 걸릴 수 있음)

---

## STEP 5. 접속 정보 확인 (제일 중요 — 이걸 넘겨주셔야 합니다)

개통되면 **접속 정보**가 나옵니다(카페24 콘솔 또는 개통 안내 메일). 아래 3가지를 메모하세요.

1. **서버 IP 주소** — 예: `123.45.67.89`
2. **접속 계정** — 보통 `root`
3. **비밀번호** (카페24가 초기 비밀번호를 알려줍니다)

> 💡 못 찾으면 카페24 **"나의 서비스 관리 → 서버 관리 → 접속정보(root 비밀번호)"** 근처를 보세요.

---

## STEP 6. 방화벽 (카페24 콘솔에 방화벽 설정이 있으면)

외부에서 접속할 **포트 3개**만 열어두세요.

| 포트 | 용도 |
|---|---|
| **22** | 서버 관리 접속(SSH) |
| **80** | 웹(http) |
| **443** | 웹 보안(https) |

> 카페24 VPS 는 기본적으로 열려 있는 경우가 많습니다. 설정이 안 보이면 넘어가셔도 됩니다.
> (개발자가 서버 안에서 처리할 수 있습니다.)

---

## STEP 7. 개발자에게 전달할 것 ✅

- [ ] **서버 IP 주소**
- [ ] **접속 계정** (보통 root)
- [ ] **비밀번호**

### 🔒 안전하게 전달하는 법

비밀번호는 **아무 채팅에나 붙여넣지 마세요.** 새어나가면 서버가 털립니다.

- 카톡 일반 대화 ❌
- **추천**: 전화로 불러주거나 카톡 **"비밀채팅"**/문자로 짧게.
- 전달 후 개발자가 접속을 확인하면 **초기 비밀번호는 바꾸는 게** 좋습니다.

---

## STEP 8. 도메인 연결 (가비아에서 — 개발자와 함께 해도 됨)

도메인은 가비아에 있으니 **가비아에서** 주소를 카페24 서버로 이어줍니다.

1. 가비아 로그인 → **My가비아 → 도메인 → DNS 관리(레코드 수정)**
2. `monsterhouse.co.kr` 의 **A레코드** 값을 **STEP 5의 카페24 서버 IP** 로
3. `www` 도 같은 IP 로 A레코드 추가

> 이 단계는 개발자가 서버 설치할 때 함께 하는 게 편합니다. 헷갈리면 IP만 넘기고 맡기셔도 됩니다.
