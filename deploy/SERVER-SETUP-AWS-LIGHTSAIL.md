# AWS Lightsail 서버 만들기 — 사장님용 가이드

MONSTER HOUSE 웹사이트를 올릴 **서버**를 AWS Lightsail에서 만드는 과정입니다.
서버를 만들고 **접속 정보 2가지(고정 IP + 키 파일)를 개발자에게 전달**하면 나머지 설치는 개발자가 합니다. (약 20~30분)

> 💡 **도메인(monsterhouse.co.kr)은 가비아에 그대로 둡니다.** 서버만 AWS에 만들고,
> 나중에 가비아에서 "주소 연결"만 해주면 됩니다(STEP 8).

> ⚠️ AWS 화면은 수시로 바뀝니다. 버튼 이름이 조금 다르면
> **"인스턴스(Instance)", "고정 IP(Static IP)"** 같은 단어를 기준으로 찾으시면 됩니다.
> Lightsail 콘솔은 **한국어**를 지원합니다(우측 상단에서 언어 변경).

---

## 준비물

- **본인 명의 휴대폰** (본인인증용)
- **신용/체크카드** (AWS 계정 등록에 필수 — 소액 승인 확인만 하고 실제 청구는 나중)
- **이메일 주소**

---

## STEP 1. AWS 계정 만들기

1. https://aws.amazon.com/ko 접속 → **"AWS 계정 생성"**
2. 이메일·비밀번호·계정 이름 입력
3. 연락처 정보(개인) 입력
4. **결제 카드 등록** (계정 확인용. 서버를 만들기 전엔 청구되지 않습니다)
5. 휴대폰 문자/전화 **본인인증**
6. 지원 플랜은 **"기본 지원 - 무료"** 선택

> ⚠️ 계정 생성은 5~10분 걸릴 수 있고, 드물게 카드 확인에 몇 시간 걸립니다.
> 다 되면 이메일이 옵니다.

---

## STEP 2. Lightsail 들어가기

1. AWS 로그인 후 상단 검색창에 **`Lightsail`** 입력 → 클릭
2. Lightsail 콘솔이 열립니다. (우측 상단에서 언어를 **한국어**로 바꿀 수 있습니다)

> Lightsail = AWS의 "간편 서버" 서비스입니다. 복잡한 설정 없이 서버 한 대를 쉽게 만듭니다.

---

## STEP 3. 리전(지역) 확인 — 꼭 서울로

인스턴스를 만들기 전에 **지역이 "서울"인지** 확인하세요.

- 화면 어딘가의 지역 선택에서 **"서울 (ap-northeast-2)"** 선택
- ⚠️ 미국 등으로 되어 있으면 사이트가 **느려집니다.** 반드시 **서울**.

---

## STEP 4. 인스턴스(서버) 만들기

1. **"인스턴스 생성"** 버튼 클릭
2. **플랫폼**: **Linux/Unix**
3. **블루프린트**: **"OS 전용(OS Only)" → Ubuntu 22.04 LTS**
   (WordPress 같은 게 아니라 **깨끗한 우분투**를 고르세요)
4. **플랜(요금제) 고르기** — ⚠️ 여기가 제일 중요

| 항목 | 선택 |
|---|---|
| 메모리(RAM) | **4GB** 플랜 |
| CPU | 2 vCPU (4GB 플랜에 포함) |
| SSD | 80GB (플랜 포함) |
| 월 요금 | **약 $24 (≈ 3만원대)** |

> ⚠️ **꼭 4GB 플랜으로.** 이 사이트는 백엔드와 데이터베이스를 한 서버에서 같이 돌려서,
> 1~2GB 로 하면 서버가 자꾸 뻗습니다. (제일 싼 플랜 고르면 안 됩니다)
> Lightsail은 첫 3개월 무료 프로모션이 붙기도 하지만, **플랜은 4GB로 고르세요.**

5. **인스턴스 이름**: 아무거나 (예: `monsterhouse`)
6. **"인스턴스 생성"** 클릭 → 1~2분 뒤 "실행 중(Running)" 이 됩니다.

---

## STEP 5. 고정 IP(Static IP) 연결 — ⚠️ 꼭 해야 합니다

기본 IP는 **서버를 껐다 켜면 바뀝니다.** 그러면 도메인 연결이 깨집니다.
그래서 **바뀌지 않는 고정 IP**를 붙여야 합니다.

1. Lightsail 콘솔 → **"네트워킹(Networking)"** 탭
2. **"고정 IP 생성(Create static IP)"**
3. 방금 만든 인스턴스(`monsterhouse`)에 **연결(Attach)**
4. 생성된 **고정 IP 주소를 메모** (예: `13.125.xx.xx`) — 이게 STEP 7에서 넘길 값입니다.

> 💡 고정 IP는 인스턴스에 **붙어 있는 동안은 무료**입니다. (안 붙이고 방치하면 소액 과금)

---

## STEP 6. 방화벽 — 포트 열기

외부에서 접속할 **포트**를 엽니다. Lightsail은 콘솔에서 클릭으로 합니다.

1. 인스턴스 클릭 → **"네트워킹(Networking)"** 탭
2. **방화벽(Firewall)** 에 아래가 있는지 확인하고, 없으면 **"규칙 추가"**:

| 애플리케이션 | 프로토콜 | 포트 |
|---|---|---|
| SSH | TCP | **22** (기본으로 이미 있음) |
| HTTP | TCP | **80** |
| HTTPS | TCP | **443** |

> 80, 443 두 개만 추가하면 됩니다. 22는 보통 이미 열려 있습니다.

---

## STEP 7. 개발자에게 전달할 것 ✅

Lightsail은 비밀번호가 아니라 **키 파일**로 접속합니다.

1. **고정 IP 주소** (STEP 5에서 메모한 것) — 예: `13.125.xx.xx`
2. **SSH 키 파일(.pem)**
   - Lightsail 콘솔 우측 상단 **계정(Account) → "SSH 키" 탭**
   - **기본 키(default key)** 를 **다운로드** (`.pem` 파일)
   - 이 파일을 개발자에게 전달

> 접속 계정 이름은 **`ubuntu`** 입니다(개발자가 알아서 씁니다). 비밀번호는 없습니다.

### 🔒 안전하게 전달하는 법

`.pem` 키 파일은 **서버의 열쇠**입니다. 새어나가면 서버가 털립니다.

- 카톡 일반 대화에 그냥 올리기 ❌
- **추천**: 카톡 **"비밀채팅"** 또는 문자로. 또는 개발자와 정한 안전한 방법으로.
- 전달 후, 개발자가 접속을 확인하면 됩니다.

---

## STEP 8. 도메인 연결 (가비아에서 — 개발자와 함께 해도 됨)

도메인은 가비아에 있으니 **가비아에서** 주소를 AWS 서버로 이어줍니다.

1. 가비아 로그인 → **My가비아 → 도메인 → DNS 관리(레코드 수정)**
2. `monsterhouse.co.kr` 의 **A레코드** 값을 **STEP 5의 고정 IP** 로
3. `www` 도 같은 고정 IP 로 A레코드 추가

> 이 단계는 개발자가 서버 설치할 때 함께 하는 게 편합니다. 헷갈리면 IP만 넘기고 맡기셔도 됩니다.

---

## 예상 비용

| 항목 | 대략 |
|---|---|
| Lightsail 인스턴스 (4GB) | **월 $24 (≈ 3만원대)** |
| 고정 IP | **0원** (인스턴스에 붙어 있으면 무료) |
| 트래픽 | 플랜에 포함 (충분) |
| 도메인 | 이미 보유 (가비아, 연 갱신비만) |
| HTTPS 인증서 | **0원** (개발자가 무료로 설정) |

> 달러로 청구되어 카드 환율에 따라 3~3.5만원 정도로 보시면 됩니다.
> AWS는 **월말에 사용한 만큼** 카드로 청구됩니다.

---

## 막히면

- 계정/결제가 막히면: AWS는 한국어 지원 채팅이 있습니다(콘솔 우측 하단).
- 인스턴스 종류가 헷갈리면: **"Lightsail, Ubuntu 22.04, 4GB 플랜, 서울 리전"** 이 문장을 기준으로 고르세요.
- 접속 정보(고정 IP·키 파일)를 못 찾으면: 화면 스크린샷을 개발자에게 보내면 짚어드립니다.

---

## ⚠️ 한 가지 주의 (비용)

- 서버는 **켜 두는 동안 요금**이 나갑니다(월정액). 사이트를 운영하는 동안은 계속 켜 둡니다.
- 나중에 운영을 접으면 **인스턴스 삭제 + 고정 IP 해제**를 해야 요금이 멈춥니다(개발자가 정리해 드립니다).
- AWS 결제 알림을 받으려면: 콘솔에서 **결제 알림(Billing alert)** 을 걸어둘 수 있습니다(개발자가 설정 도와드림).
