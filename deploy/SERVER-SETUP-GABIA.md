# 가비아 서버 만들기 — 사장님용 가이드

MONSTER HOUSE 웹사이트를 올릴 **서버**를 만드는 과정입니다.
서버를 만들고 **접속 정보 3가지를 개발자에게 전달**하면, 나머지 설치는 개발자가 합니다.
어렵지 않습니다. 천천히 순서대로만 따라오세요. (약 15~20분)

> ⚠️ 가비아 화면은 수시로 바뀝니다. 버튼 이름이 조금 다르면
> **"클라우드 서버", "g클라우드"** 같은 단어를 기준으로 찾으시면 됩니다.

---

## 준비물

- **본인 명의 휴대폰** (본인인증용)
- **결제 수단** (신용/체크카드 또는 계좌이체)
- 도메인 `monsterhouse.co.kr` 은 이미 가비아에 있으니 그 계정을 그대로 쓰면 됩니다.

---

## STEP 1. 가비아 로그인 (또는 회원가입)

1. https://www.gabia.com 접속
2. 도메인을 산 그 **가비아 계정으로 로그인**
   - 계정이 없거나 다른 곳에서 샀다면 회원가입 → 본인인증

---

## STEP 2. "클라우드 서버(g클라우드)" 신청

⚠️ **여기가 제일 중요합니다. 반드시 "서버"를 사야 합니다.**

- 상단 메뉴에서 **"클라우드"** 또는 **"g클라우드 / 클라우드 서버"** 를 찾아 들어갑니다.
- **하지 말 것**: **"웹호스팅"**, **"단독서버"** 는 고르지 마세요.
  웹호스팅은 우리 사이트를 못 돌립니다.

| 사야 하는 것 ✅ | 사면 안 되는 것 ❌ |
|---|---|
| **클라우드 서버 / g클라우드** | 웹호스팅 |
| | 도메인 (이미 있음) |
| | 메일호스팅 |

"신청하기" 또는 "서버 생성" 버튼을 누릅니다.

---

## STEP 3. 서버 사양 고르기

아래대로만 선택하세요.

| 항목 | 선택 |
|---|---|
| **운영체제(OS)** | **Ubuntu 22.04** (없으면 Ubuntu 최신 LTS) |
| **CPU / 메모리** | **2 vCPU · 메모리 4GB** (최소 2GB) |
| **디스크(SSD)** | **40GB 이상** |
| 지역/존 | 국내(서울/한국) 아무거나 |
| 요금제 | **월 정액** (종량제보다 예측이 쉬움) |

> 나중에 손님이 많아지면 사양은 클릭 몇 번으로 올릴 수 있습니다. 처음엔 위 사양으로 충분합니다.

---

## STEP 4. 결제

- 서버 이름은 아무거나 (예: `monsterhouse`)
- 결제하면 **몇 분 안에** 서버가 만들어집니다.

---

## STEP 5. 접속 정보 확인 (제일 중요 — 이걸 넘겨주셔야 합니다)

서버가 생성되면 관리 화면(콘솔)에 **접속 정보**가 나옵니다. 아래 3가지를 찾아서 메모하세요.

1. **공인 IP 주소** — 예: `123.45.67.89` (숫자.숫자.숫자.숫자)
2. **접속 계정** — 보통 `root` 또는 `ubuntu`
3. **비밀번호** 또는 **SSH 키(.pem/.ppk 파일)**
   - 가비아가 초기 비밀번호를 메일/화면으로 주거나, 직접 정하게 합니다.
   - SSH 키 파일을 받는 방식이면 그 **파일**을 잘 보관하세요.

> 💡 찾기 어려우면 콘솔에서 **"접속정보", "SSH 접속", "콘솔 접속", "비밀번호 재설정"** 같은 메뉴를 보세요.

---

## STEP 6. 방화벽 열기 (콘솔에 방화벽/보안그룹 설정이 있으면)

외부에서 접속할 **포트 3개**만 열어두세요. (나머지는 닫힌 채가 안전합니다)

| 포트 | 용도 |
|---|---|
| **22** | 서버 관리 접속(SSH) |
| **80** | 웹(http) |
| **443** | 웹 보안(https) |

> 이 설정 메뉴가 안 보이면 그냥 넘어가셔도 됩니다. 개발자가 서버 안에서 처리할 수 있습니다.

---

## STEP 7. 개발자에게 전달할 것 ✅

아래를 개발자에게 주시면 **여기서 사장님 할 일은 끝**입니다.

- [ ] **공인 IP 주소**
- [ ] **접속 계정** (root 또는 ubuntu)
- [ ] **비밀번호** 또는 **SSH 키 파일**

### 🔒 안전하게 전달하는 법

비밀번호/키는 **아무 채팅에나 붙여넣지 마세요.** 새어나가면 서버가 털립니다.

- 카톡 일반 대화 ❌
- **추천**: 비밀번호는 전화로 불러주거나, 카톡 **"비밀채팅"** 또는 문자로 짧게.
  키 파일은 개발자와 정한 안전한 방법으로.
- 전달 후, 개발자가 접속을 확인하면 **초기 비밀번호는 바꾸는 게** 좋습니다.

---

## STEP 8. (선택) 도메인 연결 — 개발자와 함께 해도 됩니다

도메인도 가비아에 있으니 같은 계정에서 바로 연결됩니다.

1. 가비아 → **My가비아 → 도메인 → DNS 관리(레코드 수정)**
2. `monsterhouse.co.kr` 의 **A레코드** 값을 **STEP 5의 공인 IP** 로
3. `www` 도 같은 IP 로 A레코드 추가

> 이 단계는 개발자가 서버 설치할 때 함께 하는 게 편합니다. 헷갈리면 IP만 넘기고 맡기셔도 됩니다.

## 예상 비용

| 항목 | 대략 |
|---|---|
| 클라우드 서버 (4GB) | **월 3만 ~ 4만원대** |
| 도메인 | 이미 보유 (연 갱신비만) |
| 그 외 (HTTPS 인증서 등) | **0원** (개발자가 무료로 설정) |

**월 3~4만원대**로 보시면 됩니다. 개발·설치 추가비는 없고, 서버 월 요금만 나갑니다.

## 막히면

- 서버 종류가 헷갈리면: **"클라우드 서버(g클라우드), Ubuntu, 4GB"** 이 문장 그대로 가비아 상담(1544-4370)에 말하면 됩니다.
- 접속 정보를 못 찾으면: 콘솔 스크린샷을 개발자에게 보내면 짚어드립니다.
